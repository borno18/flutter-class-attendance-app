# Class Attendance App

A simple Flutter application to take class attendance, manage students, and view attendance analytics.

## Features
- **Welcome Page**: Easy navigation to teacher classes.
- **Teacher Page**: View all assigned classes.
- **Class Page**: 
  - View students and their current attendance status.
  - Add new students to the class dynamically.
  - Direct access to roll call and analytics.
- **Calling Names (Roll Call)**: Step-by-step attendance marking for Present and Absent.
- **Analytics**: Real-time breakdown of who is Present, Absent, and Not Marked.

## Getting Started
To run this project locally:
```bash
flutter pub get
flutter run
```
